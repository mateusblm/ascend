# Guias de agentes

O Ascend V1 e um produto de progressao pessoal: autenticacao, perfil, atributos, missoes pessoais, sequencia e ruptura semanal individual.

Use Flutter/Riverpod no cliente, Java/Spring Boot no backend e PostgreSQL/Flyway para dados de jogo. Firebase Auth e somente identidade. Nunca usar Firestore para persistencia de jogo.

Antes de alterar regras de recompensa, leia `docs/ai/source-of-truth.md` e rode `flutter analyze` e `mvn clean test`.
