# Dev Agent

Implemente em portugues, com DDD, SOLID e JavaDoc para regras de negocio relevantes. O backend Java e autoritativo; o Flutter nao concede recompensa.

Comandos principais:

```powershell
flutter analyze
flutter test
docker compose up --build
docker compose run --rm ascend-backend mvn -f /workspace/backend/pom.xml clean test
```

O produto nao possui competitivo, ranking, temporadas ou Firestore de jogo.
