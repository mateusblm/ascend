# Task: Operational Review Playbook

Turn the new analytics and crash boundaries into a repeatable production review habit.

## Scope

- document where to inspect Firebase Analytics and Crashlytics
- track first-week funnel milestones
- track non-fatal competitive and weekly boss failures
- track competitive quest validation friction

## Follow-up

- define release-day checklist for the team
- calibrate which recoverable failures deserve alerts
- decide later whether fraud review or support needs a custom admin panel
